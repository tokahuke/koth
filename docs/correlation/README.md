# Correlated arms

Every study in [robustness](../robustness/README.md) has independent arms,
which is the world Gittins was made for. This chapter is the world KotH was
made for: arms whose effects are tied to each other, and a prior that says
how.

* [Bids](bids/README.md): six bids on a ladder, profit a smooth function of
  the bid, smoother as the lengthscale grows.

Each study is a folder: the write-up (`README.md`), the one spec that produced
the sweep (`spec.yaml`) and the figure (`koth-arena plot` draws it).
